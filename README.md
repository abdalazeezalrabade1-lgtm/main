# مساعد عبدالعزيز — وكيل شخصي للأعمال والمبيعات والتسويق

وكيل ذكاء اصطناعي يعمل على خادمك، بواجهة عربية RTL، مبني على Claude API. يدير المحادثة والذاكرة الدائمة والمهام والمشاريع والملفات والتقارير والمهام المجدولة، مع مصادقة وحدود للتكلفة وسجل للإجراءات.

## التشغيل السريع

المتطلبات: Node.js 22.13 أو أحدث (يستخدم SQLite المدمج في Node، فلا حاجة لقاعدة بيانات خارجية).

```bash
npm install
cp .env.example .env
# عدّل .env: ضع ANTHROPIC_API_KEY و APP_PASSWORD
npm start
# افتح http://127.0.0.1:3000
```

- الخادم **لا يبدأ** دون كلمة مرور (`APP_PASSWORD` أو `APP_PASSWORD_HASH`).
- الأفضل حفظ تجزئة كلمة المرور بدل النص الصريح:
  ```bash
  npm run hash-password -- "كلمة-مرور-قوية-طويلة"
  # انسخ السطر الناتج APP_PASSWORD_HASH=... إلى .env واحذف APP_PASSWORD
  ```
- دون `ANTHROPIC_API_KEY` تعمل الواجهة والذاكرة والمهام والملفات، لكن المحادثة مع الوكيل تُرفض برسالة واضحة، والتشغيلات المجدولة تُسجَّل فاشلة.

الاختبارات: `npm test`

## ما الذي يعمل الآن

| القسم | الوظيفة |
|---|---|
| المحادثة | بث مباشر للرد، إرفاق ملفات، عرض الأدوات المستخدمة والمصادر، زر **إيقاف المهمة**، عرض التكلفة وعدد الخطوات |
| الذاكرة | عرض وإضافة وتعديل وحذف وبحث. كل عنصر موسوم **مؤكد** أو **استنتاج**، ومصدره (أنت / الوكيل). يرفض النظام حفظ كلمات المرور والمفاتيح وأرقام البطاقات ورموز التحقق |
| المهام والمشاريع | أولويات (عاجلة/عالية/متوسطة/منخفضة)، حالات (للتنفيذ/قيد التنفيذ/متوقفة/منجزة/ملغاة)، مواعيد، إبراز المتأخر، ملخص الحالة |
| الملفات | رفع PDF والصور وExcel (xlsx) وWord (docx) وTXT/MD/CSV/TSV/JSON/HTML وتمريرها لـ Claude للتحليل (Excel يُحوَّل إلى CSV لكل ورقة). الوكيل ينشئ تقارير (HTML بقالب عربي RTL، Markdown، CSV متوافق مع Excel) قابلة للعرض والتنزيل |
| المجدولة | مجدول cron فعلي (croner) داخل الخادم، مع سجل تنفيذ لكل تشغيل، وتشغيل يدوي فوري، وإيقاف مؤقت. أقل فاصل 15 دقيقة |
| الموافقات | الحذف النهائي وإرسال البريد لا يُنفَّذان إلا بعد موافقتك، مع معاينة كاملة للمستلمين والنص |
| المتاجر | سلة وShopify **للقراءة فقط**: الطلبات، المنتجات، المخزون، المبيعات. البيانات الشخصية للعملاء مختصرة (الاسم والمدينة فقط) |
| السجل | كل إجراء وخطأ واستدعاء أداة، مع تكلفة كل تشغيل. الأسرار تُنقَّح قبل الكتابة |
| الإعدادات | تعديل الحدود (الخطوات، تكلفة المهمة، الحد اليومي) وحالة كل تكامل |

### سلوك الوكيل
- يضع خطة موجزة للمهام المعقدة، ينفّذ بالأدوات، ويتحقق من النتيجة.
- ينفّذ مباشرة الأعمال الداخلية القابلة للتراجع (المهام، المشاريع، الذاكرة، المستندات، الجدولة).
- الحذف النهائي ← طلب موافقة. الإرسال للآخرين/النشر/الشراء/تعديل بيانات خارجية ← غير موصولة أصلًا؛ يجهّز المسودة فقط.
- محتوى الملفات وصفحات الويب يُعامل كبيانات لا كتعليمات.
- لا يدّعي البحث إن كانت الأداة معطلة؛ ويذكر المصادر وأعمار الصفحات عند البحث.
- عند فشل أداة، تُعاد رسالة الخطأ للنموذج ليحاول بديلًا، ويُسجَّل الخطأ.

## ما يحتاج مفاتيح أو ربطًا خارجيًا

| التكامل | الحالة | المطلوب |
|---|---|---|
| Claude API | يحتاج مفتاحًا | `ANTHROPIC_API_KEY` من [Claude Console](https://platform.claude.com/settings/keys) |
| البحث عبر الإنترنت | معطّل افتراضيًا | فعّل Web Search لمؤسستك في Claude Console، ثم `WEB_SEARCH_ENABLED=true`. التكلفة 10$ لكل 1000 بحث + التوكنات |
| متجر سلة | جاهز، يحتاج رمزًا | `SALLA_ACCESS_TOKEN` من تطبيقك في [Salla Partners](https://salla.partners) بصلاحيات `orders.read` و`products.read`. رموز سلة تنتهي — جدّدها عند خطأ 401 |
| Shopify | جاهز، يحتاج ربطًا | `SHOPIFY_SHOP` + (`SHOPIFY_ACCESS_TOKEN` أو `SHOPIFY_CLIENT_ID`/`SHOPIFY_CLIENT_SECRET` من Dev Dashboard) بصلاحيات `read_orders` و`read_products`. API `2026-07` |
| البريد (SMTP) | جاهز، يحتاج بيانات | `SMTP_HOST/PORT/USER/PASS/FROM`. لـ Gmail استخدم App Password. كل رسالة تتطلب موافقتك |
| التقويم، واتساب/Slack | **غير موصولة** — تظهر كذلك في الواجهة | تُضاف كتكامل في `server/integrations/` (انظر «إضافة تكامل») |

بعد إضافة أي بيانات أعد تشغيل الخادم، ثم استخدم زر **اختبار الاتصال** في صفحة «الإعدادات والتكاملات» (طلب قراءة خفيف، دون أي تعديل).

## البنية

```
server/
  index.js            نقطة التشغيل (يرفض البدء دون كلمة مرور)
  app.js              المسارات REST + بث SSE + ربط الخدمات
  config.js           الإعدادات من متغيرات البيئة
  auth.js             دخول بكلمة مرور (scrypt)، جلسات HttpOnly، تقييد المحاولات، حماية CSRF
  db.js               مخطط SQLite
  integrations/       سلة، Shopify، البريد — كل تكامل يُفعَّل فقط عند وجود بياناته
  agent/
    agent.js          حلقة الوكيل: Claude Messages API + tool use، حدود، إيقاف، سجل
    prompt.js         تعليمات النظام (ثابتة قابلة للتخزين المؤقت + متغيرة: التاريخ والذاكرة)
    tools.js          تعريفات الأدوات ومنفّذاتها وبوابة الموافقة
  services/           memory, tasks, files, scheduler, approvals, conversations, logs, pricing, secrets, settings, integrations
public/               الواجهة (HTML/CSS/JS بلا إطار عمل، RTL، متجاوبة، وضع داكن)
test/                 اختبارات node:test (عميل Claude وهمي + SDK حقيقي ضد خادم محاكٍ)
data/                 قاعدة البيانات والملفات (مستثناة من Git)
```

- النموذج الافتراضي `claude-opus-5` مع adaptive thinking و`effort=high`، قابل للتغيير بـ `CLAUDE_MODEL` و`CLAUDE_EFFORT`.
- مع `claude-opus-5` تُفعَّل `fallbacks: "default"` (إعادة المحاولة على نموذج بديل عند رفض الطلب لأسباب أمان). عطّلها بـ `CLAUDE_SERVER_FALLBACKS=false`.
- المفتاح يبقى في الخادم فقط؛ الواجهة لا تستقبله، والسجلات تُنقّحه.

### إضافة تكامل جديد
1. أنشئ ملفًا في `server/integrations/` يصدّر `{ id, name, configured, detail, test(), tools }` على نمط `salla.js`، ويقرأ مفاتيحه من متغيرات البيئة.
2. أي أداة تُرسل أو تنشر أو تعدّل بيانات خارجية: ضع `approval: true` و`summary` (و`validate` اختياريًا) — ستمر تلقائيًا عبر صفحة الموافقات.
3. سجّله في `server/integrations/index.js`. أدواته لا تُعرض للنموذج إلا إذا كان `configured` صحيحًا، وحالته تظهر تلقائيًا في الواجهة.
4. أضف اختبارًا في `test/integrations.test.js` بخادم محاكٍ.

### المحادثات الطويلة
كل رسالة تعيد إرسال سجل المحادثة كاملًا. عند تجاوز ~150 ألف توكن تقريبًا ينبهك الوكيل لبدء محادثة جديدة (الذاكرة الدائمة تنتقل تلقائيًا). يمكن بدلًا من ذلك تفعيل الضغط التلقائي على خادم Anthropic بـ `CLAUDE_COMPACTION=true` (ميزة beta).

## الحدود والتكلفة
- **الخطوات**: كل استدعاء لـ Claude خطوة. عند بلوغ الحد تتوقف المهمة بحالة «بلغ الحد».
- **تكلفة المهمة** و**الحد اليومي** (آخر 24 ساعة): تُحسب تقديريًا من التوكنات وعدد عمليات البحث وفق الأسعار الرسمية. الفاتورة الفعلية في Claude Console.
- نموذج غير موجود في جدول الأسعار يُسعَّر بتحفّظ (10$/50$ لكل مليون) ما لم تحدد `PRICE_INPUT_PER_MTOK` و`PRICE_OUTPUT_PER_MTOK`.

## المهام المجدولة — متطلبات الاستمرار
- المجدول يعمل **داخل عملية الخادم فقط**. إذا توقف الخادم أو نام الجهاز لا تُنفَّذ المهام.
- المواعيد التي تفوت أثناء التوقف تُسجَّل «فائت» عند إعادة التشغيل ولا تُنفَّذ بأثر رجعي.
- للتشغيل المستمر شغّله على خادم دائم مع مدير عمليات، مثال systemd:

```ini
# /etc/systemd/system/agent.service
[Unit]
Description=Abdulaziz Agent
After=network.target
[Service]
WorkingDirectory=/opt/agent
ExecStart=/usr/bin/npm start
Restart=always
User=agent
[Install]
WantedBy=multi-user.target
```

## الإتاحة عبر الإنترنت
1. استخدم `APP_PASSWORD_HASH` بكلمة مرور قوية.
2. ضع الخادم خلف HTTPS (Caddy أو Nginx) واترك `HOST=127.0.0.1`، واضبط `SECURE_COOKIES=true`.
3. لا تفتح المنفذ 3000 مباشرة للعامة.
4. انسخ مجلد `data/` احتياطيًا بانتظام (قاعدة البيانات والملفات).

## ما تم اختباره
`npm test` — 36 اختبارًا ناجحًا، تغطي:
- المصادقة: رفض الوصول دون جلسة، كلمة مرور خاطئة، تقييد 5 محاولات، ترويسة CSRF، الخروج.
- الذاكرة: CRUD، رفض الأسرار عند الإضافة والتعديل، فصل المؤكد عن المستنتج في تعليمات النموذج.
- المهام: التحقق من المدخلات، المتأخرة، الإغلاق.
- حلقة الوكيل: استدعاء أداة ثم رد، حد الخطوات، حد التكلفة، الحد اليومي، الإيقاف أثناء التوليد، بوابة الموافقة للحذف، أخطاء الأدوات، فشل الـ API، الرفض، منع تشغيلين متزامنين، بدون مفتاح.
- البحث: تعريف الأداة عند التفعيل فقط، استخراج المصادر وأعمار الصفحات.
- الملفات: رفض الأنواع غير المدعومة، الأسماء العربية، تمرير المرفقات للنموذج، إنشاء تقرير HTML وتنزيله، عرضه في وضع sandbox.
- الجدولة: التحقق من cron، تشغيل فعلي مع سجل، تسجيل المواعيد الفائتة، الفشل الواضح دون مفتاح.
- التكاملات: سلة (خادم محاكٍ: الترويسات، المعاملات، تقليل البيانات الشخصية، خطأ 401، عدم ظهور الرمز في السجلات)، Shopify (client credentials وتخزين الرمز، GraphQL، حد 50)، البريد (لا إرسال قبل الموافقة، رفض العناوين الخاطئة قبل إنشاء الطلب، الرفض لا يرسل)، إخفاء أدوات التكاملات غير المهيأة.
- Excel/Word: استخراج النص العربي، ورفض الملف التالف برسالة واضحة.
- الضغط الاختياري للسياق، والتنبيه للمحادثات الطويلة.
- **SDK حقيقي** (`@anthropic-ai/sdk`) ضد خادم محلي يحاكي Messages API: البث، tool use، ترويسة fallbacks، الإيقاف، رسالة خطأ المفتاح.
- الواجهة: فُحصت يدويًا بمتصفح Chromium (سطح المكتب والجوال 390px) دون أخطاء JavaScript.

**لم يُختبر**: اتصال فعلي بـ Claude API وأداة البحث وضغط السياق، وواجهات سلة وShopify وSMTP الحقيقية (لم تتوفر مفاتيح أثناء البناء؛ اختُبرت ضد خوادم محاكية مبنية على التوثيق الرسمي). أول تشغيل بمفتاحك هو التحقق النهائي — راجع صفحة «السجل» عند أي خطأ.
